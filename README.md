# Чеки из почты (MVP)

Приложение для личного использования. Оно читает почту по IMAP, берёт только письма от одного разрешённого
отправителя, находит в них электронные кассовые чеки (ОФД) и показывает позиции в ленте.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # в Windows: copy .env.example .env
# заполните .env
streamlit run app.py
```

Откроется страница в браузере. Кнопка «Проверить почту» запускает проверку вручную, а пока страница открыта,
почта проверяется сама каждые `AUTO_REFRESH_MINUTES` минут.

## Пароль приложения

С основным паролем IMAP не работает, нужен отдельный «пароль приложения».

**Gmail**
1. Включите двухэтапную аутентификацию: myaccount.google.com → «Безопасность».
2. Откройте myaccount.google.com/apppasswords, создайте пароль (любое имя, например «чеки»).
3. Скопируйте 16 символов без пробелов в `IMAP_PASSWORD`.
4. IMAP в Gmail включён по умолчанию. Если нет: Настройки → «Пересылка и POP/IMAP» → включить IMAP.
5. `IMAP_HOST=imap.gmail.com`, `IMAP_PORT=993`.

**Яндекс**
1. id.yandex.ru → «Безопасность» → «Пароли приложений» → «Почта» → создать.
2. В настройках почты: «Все настройки» → «Почтовые программы» → отметьте «С сервера imap.yandex.ru по протоколу IMAP»
   и способ авторизации «Пароли приложений и OAuth-токены».
3. `IMAP_HOST=imap.yandex.ru`, `IMAP_PORT=993`.

**Mail.ru**
1. Настройки аккаунта → «Безопасность» → «Пароли для внешних приложений» → добавить (доступ: «Только чтение и запись
   почты» или похожий).
2. `IMAP_HOST=imap.mail.ru`, `IMAP_PORT=993`.

## Как это работает

1. IMAP: ящик открывается **только на чтение** (`readonly`), письма забираются через `BODY.PEEK`. Ничего не
   удаляется и не помечается прочитанным.
2. Берутся письма за последние `SINCE_DAYS` дней, из них только те, чей отправитель точно совпадает с одним из
   адресов в `ALLOWED_SENDER` (можно перечислить несколько через запятую). Поиск FROM на сервере не используется:
   у Яндекса он не находит свежие письма.
3. Из письма достаются HTML- и текстовые части, текст PDF-вложений и вложенные `.eml` (пересылка вложением).
4. Сначала разбор кодом:
   - HTML-таблица с колонками «Наименование / Цена / Кол-во / Сумма»;
   - строки вида `2 x 89,99 = 179,98` (название в той же или в предыдущей строке);
   - блоки `Цена … / Кол-во … / Сумма …`.
   Плюс итог, дата, магазин, ФН/ФД/ФП и ссылки на сайт ОФД.
5. Если позиций не нашлось или их сумма не сходится с итогом, а в письме есть признаки чека, текст уходит
   в Claude API (если задан `ANTHROPIC_API_KEY`). Ответ приходит строго по JSON-схеме, затем проверяется
   (`validate_llm_result`).
6. Результат и Message-ID сохраняются в SQLite (`receipts.db`), так что повторно письмо не разбирается.
   Само письмо не сохраняется, только распознанный результат и тема.

Если в письме только ссылка на чек (например, у Магнита), приложение само скачивает чек с сайта ОФД:
HTML-страницу или PDF, в том числе PDF, который страница показывает внутри себя. Если и там позиций нет,
в ленте будет «Позиций в письме нет» и ссылка на чек. Такие письма перепроверяются при каждой проверке почты.

Чтобы разобрать письма заново, удалите `receipts.db`.

## Тестирование на локальных файлах

```bash
python parse_sample.py samples/perekrestok_ofd_table.html
python parse_sample.py samples/forwarded_pyaterochka.eml --no-llm
```

Скрипт печатает распознанный JSON и текст, как в ленте. Понимает `.eml`, `.html`, `.pdf`, `.txt`.
`--no-llm` отключает обращение к Claude API, `--no-fetch` — скачивание чека по ссылке.

Тестовые примеры в `samples/` (данные выдуманные):
- `perekrestok_ofd_table.html` — чек ОФД в виде HTML-таблицы, есть весовой товар;
- `forwarded_pyaterochka.eml` — пересланное письмо, чек в цитате, формат «Цена / Кол-во / Сумма»;
- `link_only.eml` — в письме только реквизиты и ссылка на ОФД.

Настоящее письмо можно сохранить как `.eml`: в Gmail «⋮ → Скачать сообщение», в Яндексе и Mail.ru
«Ещё → Скачать/Сохранить письмо». Положите его в `samples/` и запустите `parse_sample.py`.

## Файлы

- `app.py` — Streamlit-интерфейс;
- `mail_client.py` — чтение IMAP;
- `receipt_parser.py` — весь разбор чеков и форматирование;
- `storage.py` — SQLite;
- `config.py` — настройки из `.env`;
- `parse_sample.py` — разбор локальных файлов.
